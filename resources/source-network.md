# 信源网络

本页公开说明来源职责、公开门槛与健康分；不包含密钥、请求日志或未核验线索正文。下一次日报生成后会按近 30 天数据自动刷新每个来源的状态和评分。

## 四层网络

- **官方公司与实验室**：arXiv Robotics、NVIDIA Newsroom、Google DeepMind Blog、Google AI Blog。用于一手技术、产品和研究事实。
- **开源发布**：LeRobot、Isaac Lab、OpenPI、OpenVLA 的 GitHub Releases。用于验证版本、模型、代码与数据发布。
- **权威产业媒体**：IEEE Spectrum Robotics、TechCrunch Robotics。可补充产品和部署；融资必须有一手证据或两家独立媒体交叉确认。
- **线索发现层**：Google News、Hacker News、X 与自动发现 RSS。只进入候选层，不能直接出现在公开资讯中。

## 健康分与状态

健康分 = 成功率 30% + 相关命中率 25% + 最终公开收录率 30% + 事后纠错质量 15%。样本不足 5 次不自动降权；低于 65 分进入“观察”，连续低于 45 分或访问受限时“已暂停”。
