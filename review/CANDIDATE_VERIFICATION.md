# 公司 / 融资候选二次核验规则

该流程把线索转化为可审计的分级信号。首页可以展示证据状态，规范事件中心和公司资本档案仍保持更高的确认门槛。

## 证据门槛

- **官方确认**：公司、投资方、交易所或监管机构的一手披露。
- **多方证实**：至少两个真正独立的权威来源，且主体和公开字段没有冲突。
- **正在发生**：主体明确、一个权威来源支持、没有事实冲突；首页明确提示仍待官方或第二来源补证。
- **线索层**：Google News、HN、X 等只用于发现。无论数量多少，都不能成为公开证据。

金额、轮次和事件日期分别核验；缺失字段保持未知。分级信号不等于规范档案，只有完成事件级审核后才能进入事件中心和公司资本地图。

## 重试与纠错

- 证据不足按 1、3、7、30 天重试；高影响融资、产品和部署优先补证。
- 每轮主动扫描公司官网、已绑定官方源、权威媒体和可识别的原始媒体；重复 URL 不算新增证据。
- 新证据会绕过等待时间立即重算。
- 相同证据重复运行不增加尝试次数。
- 主体不唯一、金额或轮次冲突时保持内部状态，不得晋升。
- `review/candidate-verification.json` 是机器可读审计记录，Markdown 文件是人工 Review 视图。
