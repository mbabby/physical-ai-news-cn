## 学术与研究前沿

<!-- RESEARCH_UPDATES_START -->

- [能感知自身老化的机器：硬件感知自主智能框架](https://arxiv.org/abs/2607.28451v1)<br>自主系统的电池、传感器等会老化，但人工智能常假设硬件完好，易导致任务失败。AAAI框架将硬件健康融入推理与规划，延长寿命并提升安全性。

- [RoboBRIDGE：将策略桥接为真实世界机器人智能体的模块化框架](https://arxiv.org/abs/2607.27881v1)<br>RoboBRIDGE以五模块协同将预训练VLA编排为稳健机器人智能体，支持故障恢复与重规划，多平台实验优于独立策略。

- [RedFlow：将失败经验重定向为动作级纠正的流匹配VLA策略](https://arxiv.org/abs/2607.27782v1)<br>RedFlow是面向流匹配VLA策略的细粒度离线强化学习框架，将失败数据转化为动作级纠正监督，真实任务成功率由56.7%提升至74.7%，样本效率优于在策略方法。

- [DexDirect：面向高效灵巧演示采集的直接动觉手臂引导](https://arxiv.org/abs/2607.27784v1)<br>DexDirect 拖动手柄引导重力补偿机械臂，单摄像头将另一只手重定向到16关节灵巧手；成功演示数高于视觉和位姿跟踪基线，扩散策略抓取放置成功率达90%。

- [Arm2Air：跨形态骨架迁移实现无人机三维中继部署](https://arxiv.org/abs/2607.27627v1)<br>Arm2Air将机械臂避障骨架跨形态迁移至无人机中继部署，少量数据微调后规划耗时降64.9%、瓶颈容量升32.6%。

- [基于流匹配世界模型的手术机器人模仿策略故障检测](https://arxiv.org/abs/2607.27511v1)<br>FoMo-FD以流匹配世界模型学习正常视觉动态，无需失败样本即可检测手术机器人故障，检出率96.6%、误报率1.3%。
