# GitHub 首页优先：极简阅读规格

## 目标与取舍

以仓库 README 为唯一主阅读入口，帮助非专业读者看懂物理 AI 当前进展。不再把用户引向独立网站才能读完内容，不再新增公开页面。

保留定位与标题：**物理 AI 进展解读**。简介：**看懂机器人与物理 AI：现在能做什么，最近进步在哪，还有什么没解决。**

采用 GitHub 原生文档排版，而非另建极简网站或将整个数据库平铺成无限长页面。“所有信息”在本期指当前公开阅读内容、其背景、局限和证据，以及公司/研究/技术资料的当前公开摘要；原始数据、完整历史和审计记录继续存储在仓库，不复制到首屏。候选和未核验材料不得因集中展示而升级为公开事实。

## README 阅读结构

1. 一个普通一级标题、一句简介、一行内容更新时间与简短状态；不放横幅、英文刊头、徽章墙或大段使用说明。
2. 近期解读最多三篇，标题下直接阅读。第一段为原有两句事实及有依据的变化；第二段以“解读：”和“局限：”短标签明确解释与边界，不重复堆叠小标题或卡片框。
3. 每篇末尾一个“背景与证据”折叠区，完整保留来源链接、背景、事件/披露/实质变化日期，以及存在时的可比条件与对比。未知保持未知，历史内容明确标记，不能以检查日期充当事件日期。
4. 公司进展、研究论文、技术背景各一个独立折叠区，当前公开摘要在本页读完，不以“打开网站查看”代替正文。只展示已有且合格的内容；缺内容不补模板、泛行业盘点或推测。避免旧版多层嵌套和重复摘要。
5. 底部折叠“更新与纠错”，集中放运行健康、数据口径、纠错和贡献入口。英文简介可折叠内联；原 English README 保留兼容，但不是必读步骤。

页内导航仅在确有必要时使用锚点。外部链接用于原始证据、原项目或贡献操作；历史记录链接是可选查档，不作为当前内容的阅读前提。

## 简洁与诚实的状态

无新内容、生成受限、首次尚未生成分别使用一句短提示，不占用大型警告面板，不重复输出多段免责声明。失败时保留仍有效的旧解读，并附实际内容日期和简短失败状态；已撤回或证据失效的内容仍必须下架。

“内容更新”和“最近检查”分别保留，通常仅前者显著展示；运行细节放底部。简化呈现不隐藏故障，不把失败写成“没有新进展”，也不制造成功运行记录。

## 已有 Pages 全面整改

保留已有页面和旧链接，不新增路由，不删除历史档案、工作流或部署配置。README 不再以 Pages 作为主阅读入口。

已有页面不是仅做兼容保留，而是全部纳入本期视觉与阅读结构整改。当前范围固定为八页：`site/index.html`、`site/companies.html`、`site/core-coverage.html`、`site/research.html`、`site/weekly.html`、`site/watchlist-changes.html`、`site/subscribe.html`、`site/contribute.html`。

统一采用极简文档式阅读：纯色背景、普通标题、正文优先、克制的分隔与链接强调；移除网格、渐变、光晕、超大刊头、重复品牌装饰和巨型空态。缩短标题区与无意义留白，但保留正文行距、触控目标和键盘焦点。适配浅深色阅读时只使用中性色，不恢复霓虹装饰。

各页保留真实用途：公司与覆盖页保留公司事实、证据和筛选；研究页保留论文正文及复现边界；周报与变化页保留时间与变化记录；订阅和贡献页保留现有表单、链接与操作反馈。删掉重复说明和不必要的框，不删事实、风险标记或必要交互。技术细节、运行健康和长背景按需折叠，重要故障仍用短提示可见。

八页共用现有样式与组件进行有边界的整改，不另建视觉系统或增加依赖。导航清楚提供 GitHub 主阅读入口，旧 URL、查询参数、锚点和分享链接继续可用；保留页面不代表继续要求读者离开 README 才能读完当前公开内容。不维护两套独立编辑结论。

## 生成与数据边界

- 继续由同一份已校验解读 JSON 生成 README，不改事实、顺序、稳定 ID、最大三篇及证据门槛；文本组织变化不得另行调用模型重新写结论。
- 改动生成器而非仅手改 README，确保次日自动更新不会恢复外跳入口或旧排版。
- 公司、研究等摘要复用已有公开投影与证据，不从内部候选直接取内容，不新建排名或推荐体系。
- 保留生成区块标记，或在确有必要改动时同步迁移其生成器、校验器及测试；禁止破坏事务发布、幂等、撤回和既有归档。
- 不调整信源、模型配置、Secrets、调度、工作流权限；不为消除空态而实时抓取或改写运行回执。

## 验收

- GitHub README 标题和简介之后直接进入近期内容或一句真实空态；没有横幅、装饰性大图和成排导航按钮。
- 当期每篇解读的事实、变化、解读、局限、背景和证据均在本页可读；补充资料当前摘要不依赖跳转 Pages。
- 同一 JSON 在排版前后保持解读内容、顺序、数量及证据一致；异常、撤回、首次空态和历史保留都有回归测试。
- 两次隔离离线生成均通过发布校验；相同输入输出稳定，第二次不恢复旧排版或引入重复内容。
- 检查折叠区配对、锚点和原始证据链接；桌面及窄屏没有横向溢出，正文清晰，键盘能展开证据。
- 八个现有页面逐页检查桌面与窄屏、空态和有内容状态；不存在遗留网格、光晕或超大宣传刊头。公司筛选、证据展开、订阅、贡献、旧分享参数与锚点均保留并通过相应回归验证。
- 完整测试、类型检查、发布校验通过；现存上游降级单独报告，不宣称已修复。

## 本规格阶段

仅记录已讨论的设计并进行文档自检，不实施代码、真实生成、合并、推送或部署。规格通过后编写实现计划；不再重复确认定位与视觉偏好。
