## 修复范围

1. Decision Products 与 Core 集成测试使用自有固定研究样本，不再随生产缓存漂移。显式断言非空公开研究卡，并保留双次生成、跨页面一致性、回执与回滚测试。
2. 同一论文的旧核验不覆盖较新的核验；同 work 的较新撤稿记录在标题、摘要或版本变化时仍受保护。更新的解除撤稿核验和不同 work 身份更正不被永久锁死。
3. 公开研究列表先保留本轮 fresh 记录，fallback 仅补缺项，保持排序与六条上限。旧副本不能覆盖本轮元数据更正。
4. 未来 OpenAlex 核验时间不再被算为 fresh。成功的实时补全使用本轮共同观测时钟，避免网络延迟把新证据误判为未来；失败、未匹配与未配置不刷新缓存核验时间。
5. 历史日报读取有北京时间日期上界，研究文章与 registry 有发布时间上界；公开研究卡另有未来/无效日期门禁。
6. 日报超过北京时间 09:20 仍缺失时，健康汇总不再返回 healthy；失败或空发布尝试不能重置最后成功发布的老化计时。
